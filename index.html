StageVLA

A Perception-Driven Hierarchical State Machine for Few-Shot Long-Horizon Robotic Manipulation

arXiv Code

We propose StageVLA, a perception-driven hierarchical framework that integrates object states, subtasks, and atomic skills with unified Semantic Approaching Vector Generator (SAVG) and End-Effector representation (UEER), enabling robust few-shot, cross-embodiment, and spatial-background generalization in long-horizon robotic manipulation tasks.

Abstract

General-purpose robotics has gained increasing attention due to its potential to enable scalable real-world automation. Recent advances in Vision-Language-Action (VLA) models have endowed robots with the ability to interpret task intent from natural language, yet existing approaches remain limited in few-shot generalization across diverse backgrounds and object configurations in long-horizon manipulation tasks. In this work, we propose StageVLA, a perception-driven hierarchical state machine (PHSM) that integrates object states, subtasks, and atomic skills to enable closed-loop decision-making for long-horizon robotic manipulation. StageVLA decomposes skill execution into approaching and interaction phases, and introduces a unified Semantic Approaching Vector Generator (SAVG) together with a Unified End-Effector representation (UEER) to reduce action ambiguity across different robot embodiments in the approaching phase. All models are trained from a few human demonstrations, augmented through a point-cloud editing pipeline (StageGen). StageVLA is deployed through a unified real-robot execution interface (Bestman), enabling robust few-shot, cross-embodiment, and spatial-background generalization. Experimental results across multiple environments demonstrate that StageVLA consistently outperforms state-of-the-art baselines, with ablation studies validating the contribution of each component.

Method

Figure 2: StageVLA pipeline

StageVLA consists of three key modules: (A) High-Level Task Planning, where a VLM parses user instructions to construct a PHSM over object states $\mathcal{S}$ and atomic skills $\mathcal{Z}$, generating an optimal skill sequence via dynamic programming. (B) Data Synthesis & Training, where the StageGen module generate synthetic demonstrations via point cloud editing for data-efficient learning. (C) Two-Stage Execution, where the policy decomposes actions into approaching and interaction phases. SAVG predicts target poses for spatial alignment, while a DP3-MSF diffusion policy executes contact-rich interactions based on real-time state judgments from DINOv3 features. This hierarchical design enables robust, closed-loop long-horizon manipulation.

Perception-Driven Hierarcical State Machine

Figure 3: PHSM execution

Given a long-horizon task instruction, a VLM decomposes the task into subtasks based on atomic skills $\mathcal{Z}$ while extracting the object states $\mathcal{O}$ to establish the scene state space $\mathcal{S}$. A valid state transition matrix $\mathcal{T}$ is constructed under constraints. Finally, dynamic programming searches for the optimal skill sequence (red arrows) from the initial state to the goal state.

StageGen

To enable few-shot generalization, we generate synthetic demonstrations via structured point cloud editing. Our method advances DemoGen by incorporating a Unified End-Effector Formulation (UEEF), supporting object rotation, and enabling multi-granular data generation at demo, skill and grasp-pose levels.

Figure 4: StageGen pipeline

Compared to previous works on data-efficient learning for generalization, StageGen significantly enhances the model's capabilities across four key dimensions: spatial layout, background robustness, embodiment adaptability, and orientation invariance.

Semantic Approching Vector Generator

Figure 5: Illustration of SAVG

SAVG predict the SAV, which is categorized into object-centric and tool-relative cases. a) Object-Centric Case: When no tool is used, SAV depends only on object geometry and gripper configuration and it can be interpreted as a functional point. b) Tool-Relative Case: When using tools, the effective interaction point corresponds to the tool-object contact region, invariant to the end-effector grasp configuration. Since tool and end-effector form a rigid body, SAV can be represented as the transformation of end-effector. We leverage the strength of incrementally learning, forcing the model to progressively converge towards the ground truth.

Model Structure

As illustrated in Fig. 2, StageVLA incorporates SAVG and DP3-MSF to facilitate atomic skill training. Subsequently, we present ablation studies to validate the efficacy of each component.

SAVG

Figure 2: Network architecture of SAVG

For Approaching, SAVG integrates a spatially-biased cross-attention mechanism between the condition and target point clouds. Furthermore, it employs a CAVE model, conditioned on symbolic labels extracted from PHSM, to predict the SAV across diverse scenarios.

DP3-MSF

Figure 2: Network architecture of DP3-MSF

For interaction, DP3-MSF employs a diffusion process conditioned on 3D scene features (without state MLP), trained with StageGen for contact-rich manipulation.

Experiments

Simulation Experiments

We evaluate StageVLA in CoppeliaSim and IsaacSim using a Franka Panda robot, leveraging calibrated RGB-D inputs projected into world-frame point clouds. Our benchmark comprises six challenging tasks varying in viewpoint, fidelity, stage count, manipulation type, and geometric complexity, with each task assessed over 100 trials based on 200 expert demonstrations. Compared to representative 2D (DP, ACT), 3D (DP3), and vision-language (SmolVLA) baselines, StageVLA achieves a superior average success rate of 96.17%, demonstrating robust generalization across all tested dimensions.

Ablation Study

We conduct four ablation studies to validate the key design choices of StageVLA, including interaction modeling, loss formulation, point cloud backbone and fusion strategy, and the effectiveness of StageGen.

Table 1: Ablation study on DP3-MSF components.

To evaluate the efficacy of each component in DP3-MSF, we conduct an incremental ablation study starting from the base DP3 model. We define four variants: (M) utilizing object-masked point clouds; (D) and (S) trained exclusively on full or interaction-only synthetic trajectories, respectively; and (F) removing the State MLP branch (State-Free). All other variants are trained on a limited set of 50 expert demonstrations. Experiments focus on the CubeStacking task, decomposed into Pick and Place atomic skills. We report the average success rate over 100 trials (50 per skill) , where both robot initial poses and object configurations are randomly perturbed to simulate phase-transition noise and prevent trajectory replay.

Table 1: Ablation study on point cloud backbones and fusion strategies.

(a) Loss Function Analysis. We benchmark SAVG loss variants using pose MSE (XYZ + Rot6D) on an augmented test set. Candidates include: (1) Chamfer Distance on point clouds; (2) MSE + Geodesic Distance; (3) Pure Pose MSE; and (4) MSE + Relative Auxiliary Loss (Rel), which enforces consistency via iterative feedback of transformed predictions. To assess the learning of relative transformations, evaluation employs a three-step iterative refinement strategy. (b) Performance evaluation of different backbones. We evaluate three point cloud backbones (PointNet, Point- Net++, PointTransformerV3) and four fusion strategies (Con- cat, CA, ResFiLM, BiasCA).

Table 1: Impact of StageGen on data efficiency.

To evaluate data efficiency, we conduct experiments on CubeStacking with varying numbers of real demonstrations, comparing models trained with and without StageGen. For each real demonstration, StageGen generates 500 synthetic episodes. We then evaluate SAVG and DP-MF in terms of pose MSE over 20 held-out trials.
